# 第 5 讲：分布式图算法与同步器

## 一、本讲定位

本讲把前几讲的模型落到算法：节点只知道邻居信息，如何构造生成树、传播距离、求最小生成树、模拟轮次、选出 MIS、压缩路由并进行自适应复制？

统一讲法是：任何分布式图算法都要回答四个问题：

1. 节点保存什么局部状态？
2. 消息何时发送、何时接受？
3. 如何知道局部工作已经完成？
4. 如何从局部事实推出全局性质？

## 二、生成树：分布式算法的控制骨架

### 1. 同步 flooding

设一个根节点 initiator。每个节点第一次收到 root 消息时：

1. 记录发送者为 parent；
2. 设置自己的深度；
3. 向尚未访问的邻居转发。

学生常误以为“收到消息就向所有邻居转发”已经得到树。要强调：必须只接受第一个合法 parent，后续到达的消息要被抑制，否则会得到图而不是树。

### 2. 异步生成树

异步系统没有轮次，也不能用“这一轮没收到消息”判断终止。需要 ACCEPT/REJECT：

- 第一次收到探索消息：暂时认发送者为 parent，并向其他邻居查询；
- 查询邻居已经属于当前树：REJECT；
- 邻居未访问：ACCEPT，形成 child；
- 所有邻居都回复后，本节点才能向 parent 汇报完成。

这里要突出“局部终止证据”如何沿树汇聚。

### 3. 并发 initiator

若多个节点同时发起，算法必须：

- 选择最高 ID；
- 合并多个树；
- 或为每个 root 保留实例并在后续抑制。

讲 newroot 规则时让学生观察：更高优先级的根消息会替换较低根，较低根被停止继续扩散。正确性依赖优先级比较的传递性。

## 三、Broadcast 与 Convergecast

生成树建立后，广播沿树从根向叶传播；汇聚沿树从叶向根返回。

板书：

- Broadcast：父节点发送给孩子；
- Convergecast：孩子报告完成，父节点等待全部 child。

消息复杂度通常为 O(n)，时间复杂度取决于树高。说明这就是后续快照、终止检测、全局聚合和同步器的共同骨架。

## 四、最短路与 Floyd–Warshall

### 1. Bellman–Ford

每个节点保存到各目的地的当前距离 d_i(v)。收到邻居 j 的距离后：

d_i(v) ← min(d_i(v), w(i,j)+d_j(v))

同步版本按轮次更新；异步版本在距离变小时立即传播。

完整例子：链路权重 A—B=1、B—C=2、A—C=6。A 初始到 C 为 6；B 报告到 C 为 2 后，A 更新为 3。要求学生说明：每次更新都依据三角不等式，不会把距离变大。

### 2. Stale distance

异步算法中，旧距离可能晚到。安全做法是只接受更小的距离，或附带版本号；不能因为消息到达较晚就覆盖已经更优的结果。

### 3. Floyd–Warshall

全源最短路使用中间节点集合逐步扩展：

d(i,j,k) = min(d(i,j,k−1), d(i,k,k−1)+d(k,j,k−1))

分布式实现需要协调“当前允许使用哪些中间节点”，因此通常用同步轮次、sink tree 或全局状态向量。

## 五、GHS 最小生成树

### 1. Fragment 与 MWOE

GHS 把 Kruskal 的安全边思想分布式化：

- 当前若干节点组成 fragment；
- 每个 fragment 找出跨出 fragment 的最小权边 MWOE；
- 把 MWOE 加入 MST，不会形成环；
- 多个 fragment 合并成更大的 fragment。

解释安全性：对任意 fragment，跨越其 cut 的最小权边属于某棵 MST。这个 cut property 是算法正确性的核心。

### 2. 一轮的五个阶段

1. fragment leader 发 SEARCH；
2. 节点沿树向下询问边；
3. 叶节点向上 REPLY；
4. fragment 汇聚得到 MWOE；
5. 通过 ADD 合并，并选出 NEW LEADER。

讲 MST 图例时让学生分别标出 tree edge、cross edge、当前 leader 和候选 MWOE。

### 3. 同步与异步

同步 GHS 容易讲解，但依赖轮次；异步 GHS 可用同步器模拟，也可以直接设计基于消息确认的版本。提醒学生：模拟同步并不免费，安全条件会增加消息和状态。

## 六、Synchronizer

### 1. 定义

Synchronizer 在异步系统上提供同步算法需要的“安全进入下一轮”条件。它不改变底层消息模型，而是给每个节点一个本地判断：当前轮的所有必要事件已经完成。

### 2. 三类同步器

- Simple：每轮向所有邻居确认，理解简单，消息多；
- α：使用 ACK 和 safe，减少部分确认；
- β/Cluster：在生成树或簇内聚合，局部快速、全局可控。

统一成本公式：

总时间 ≈ 算法本身轮次 × 每轮同步成本  
总消息 ≈ 算法消息 + 同步控制消息

### 3. 为什么不能只说“异步更快”

异步减少等待，但会增加乱序、重复计算和终止判断。同步器提供了可证明的边界，因此常用来把成熟同步算法迁移到异步环境。

## 七、MIS、CDS 与压缩路由

### 1. Luby MIS

每轮每个节点随机选择优先级；若高于所有邻居，则进入 MIS；它和邻居从图中删除。最终集合满足：

- 独立：MIS 内任意两个节点不相邻；
- 极大：任何未入选节点至少邻接一个 MIS 节点。

讲伪代码时把“随机竞争”和“淘汰”分开，学生会更容易理解概率收敛。

### 2. CDS

Connected Dominating Set 在 MIS 之后增加连通骨架，使广播能够在较少节点上进行。可解释为数据中心中选出的“控制节点”或 GPU 组播骨干。

### 3. Compact routing

完整路由表随节点数增长过快。Interval routing/prefix routing 用区间或前缀压缩目的地址集合，代价是 stretch：路径不再一定是最短，但表空间显著下降。

要求学生明确三者取舍：表大小、路径长度、更新成本。

## 八、选主与自适应复制

### 1. LCR 与 Hirschberg–Sinclair

LCR 在环上转发 ID，最高 ID 最终胜出；消息可能达到 O(n²)。Hirschberg–Sinclair 让候选者以指数半径探测，用淘汰减少消息量。

### 2. Adaptive Data Replication

复制目标是把副本放在访问热度高且代价低的位置。树 overlay 中定义 R-neighbour 和 R-fringe：

- R-neighbour：R 内至少还有一个邻居；
- R-fringe：R 内只有一个邻居但 R 外仍有邻居；
- singleton：只有一个副本。

每个 epoch 根据读写收益、迁移成本和副本数量决定 Expansion、Contraction 或 Switch。

## 九、AI 基础设施映射

- MST/生成树：GPU 组播、模型分发、参数聚合；
- MIS/CDS：选择广播骨干、机架代表和故障隔离点；
- Leader election：模型发布 leader、控制面主节点；
- 自适应复制：热门模型、embedding、tokenizer、KV Cache。

强调：AI 系统中的“副本”不仅是数据副本，也可能是计算副本、缓存副本和控制状态副本。

## 十、课堂互动

1. 手算 Bellman–Ford 两轮更新；
2. 给三个 fragment，找每个 fragment 的 MWOE；
3. 执行一轮 Luby MIS；
4. 比较 Simple 与 Cluster synchronizer 的消息数；
5. 给 KV Cache 访问热度，选择扩张还是收缩。

### 收束句

> 图算法真正训练的是“从局部证据构造全局结构”的能力。生成树提供骨架，最短路提供度量，MST 提供安全合并，MIS 提供稀疏骨干，同步器则把这些算法放到异步现实中。

## 十、算法结论的适用范围

Bellman--Ford 的同步轮次例子假设没有负权环；异步距离向量还会遇到旧信息和 count-to-infinity。课件中的 Sync GHS 是 Borůvka 风格的教学化协议，标准 GHS 是带 level/phase 的异步协议，不能直接套用本讲轮数复杂度。分布式 Floyd--Warshall 则要求所有节点使用同一 pivot 阶段；Synchronizer 用额外消息模拟安全点，故障和分区需要另外的重配置机制。让学生在写复杂度前先写模型假设。
